# Мониторинг цен с уведомлениями в Telegram

Консольная утилита следит за ценами товаров на сайтах и присылает сообщение в Telegram, когда цена падает или достигает нужной. Цена ищется по CSS-селектору, поэтому подходит почти любой сайт.

## Возможности

- Любой сайт: цена ищется по CSS-селектору, который вы указываете при добавлении товара
- Если элемент имеет атрибут `content` (например, `meta[itemprop=price]`), берётся его значение
- Понимает разные форматы: «12 990 ₽», «£51.77», «1.299,00 €», «$1,299.99», «4 590,50 руб.»
- Уведомление в Telegram при снижении цены (с процентом) и при достижении целевой
- История цен в SQLite и текстовый график в консоли
- Режим `run` проверяет цены по расписанию
- Недоступный сайт или пропавший элемент не останавливает проверку остальных товаров
- Без настроенного Telegram уведомления выводятся в лог

## Стек

Python 3.10+, requests, BeautifulSoup4, SQLite (`sqlite3`), python-dotenv, pytest.

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python monitor.py add "https://books.toscrape.com/catalogue/a-light-in-the-attic_1000/index.html" \
  --selector "p.price_color" --name "Книга" --target 40
python monitor.py list           # список товаров
python monitor.py check          # проверить цены один раз
python monitor.py history 1      # история цен товара №1
python monitor.py remove 1       # перестать отслеживать
python monitor.py run --every 60 # проверять каждые 60 минут
python -m pytest -v
```

Тесты запускаются в GitHub Actions (`.github/workflows/tests.yml`) на Python 3.11 и 3.12.

## Настройка

Уведомления в Telegram необязательны. Переменные окружения:

| Переменная | Назначение |
|---|---|
| `TG_BOT_TOKEN` | токен бота от @BotFather |
| `TG_CHAT_ID` | ID чата, куда слать уведомления |
| `PRICE_DB` | путь к базе, по умолчанию `prices.db` |

Переменные можно задать в файле `.env` рядом со скриптом, он читается через python-dotenv (есть в `requirements.txt`):

```bash
cp .env.example .env
```

Как найти селектор: правый клик по цене, «Просмотреть код», правый клик по элементу, Copy, Copy selector.

> Перед мониторингом чужого сайта проверьте его правила использования и robots.txt и не ставьте слишком частые проверки.

## Как это устроено

- `parse_price` убирает валюту и пробелы-разделители тысяч, затем определяет десятичный разделитель: если есть и точка, и запятая, десятичным считается последний символ; одиночная запятая с 1-2 цифрами после неё считается дробной частью.
- Логика уведомлений вынесена в чистую функцию `decide`: сообщение о цели отправляется один раз, когда цена впервые опускается до неё, о снижении при каждом падении.
- В SQLite две таблицы: `items` (товар, селектор, цель, последняя цена) и `history` (все проверки с временем).
- Кодировка страницы определяется через `apparent_encoding`, чтобы кириллица на сайтах с неверным charset разбиралась правильно.
- График в `history` строится символами `█`, длина полосы нормируется между минимальной и максимальной ценой.
